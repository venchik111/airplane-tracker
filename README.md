# Трекер самолётов

Консольная программа получает границы выбранной страны из Nominatim, запрашивает самолёты в этой области через OpenSky и сохраняет текущий снимок в JSON.

## Запуск

Нужны Python 3.11 или новее и Poetry.

```bash
poetry install
poetry run python main.py
```

В PyCharm откройте папку проекта и выберите интерпретатор `.venv/bin/python`. Рабочая папка запуска — корень проекта.

Программа последовательно запрашивает:

1. Страну воздушного пространства, например `Canada`.
2. Количество самолётов в топе по высоте.
3. Страны регистрации через запятую, например `Canada, United States`. Enter отключает фильтр. Доступные названия выводятся перед запросом.
4. Нижнюю и верхнюю высоту через пробел, например `1000 12000`. Enter отключает диапазон.

Высота измеряется в метрах, скорость — в метрах в секунду. Вывод отсортирован по убыванию барометрической высоты. Отрицательная высота допустима; неизвестные измерения сохраняются как `null`. Самолёты без известной высоты в топ не включаются. Снимок всех полученных самолётов записывается в `data/aeroplanes.json`, независимо от последующей фильтрации.

Границы страны задаются прямоугольником: в него могут попадать соседние территории. Страна регистрации самолёта и страна текущего местоположения — разные данные. Пустой ответ не означает отсутствия всех самолётов: результат зависит от покрытия сети OpenSky.

## Сервисы

Используются [поиск Nominatim](https://nominatim.org/release-docs/develop/api/Search/) и [OpenSky states/all](https://openskynetwork.github.io/opensky-api/rest.html). Для Nominatim отправляется User-Agent, повторные координаты кешируются в пределах одного запуска, новые географические запросы выполняются с интервалом не меньше 1,1 секунды. Географические данные: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL.

Доступность OpenSky и квоты зависят от правил сервиса. При необходимости можно передать действующий Bearer-токен через переменную окружения `OPENSKY_TOKEN`. Не сохраняйте токен в коде или репозитории. Автоматическое получение и обновление токена не реализовано. Ошибки HTTP, ограничения запросов и сетевые сбои выводятся в консоль; программа не подменяет их демонстрационными данными.

## Устройство проекта

- `src/api.py` — абстрактный интерфейс и клиент двух API.
- `src/aeroplane.py` — валидация, доступ к атрибутам через свойства, преобразование ответа API.
- `src/storage.py` — абстрактный интерфейс хранилища и JSON-коннектор: добавление, поиск по критериям, удаление, замена снимка.
- `src/utils.py` — фильтрация и топ.
- `src/cli.py` — взаимодействие с пользователем.

`plane.compare_speed(other)` и `plane.compare_altitude(other)` возвращают -1, 0 или 1. Оператор `<` сравнивает высоты. Неизвестное измерение при прямом сравнении вызывает `ValueError`.

Добавление самолёта с тем же непустым ICAO24 обновляет запись. Для самолётов без идентификатора дубликаты определяются по всем полям. Поиск в хранилище использует точное совпадение именованных атрибутов; консольный фильтр стран не учитывает регистр. Повреждённое хранилище вызывает ошибку чтения, а не воспринимается как пустое. Запись сначала выполняется во временный файл и затем заменяет целевой файл. Параллельная запись из нескольких процессов не поддерживается.

## Проверки

```bash
poetry run pytest
poetry run black --check .
poetry run isort --check-only .
poetry run flake8 .
```

Тесты используют временные файлы и подменённые ответы HTTP, поэтому не требуют доступа к сервисам. Минимальное покрытие — 70%. После запуска доступны `coverage.xml` и HTML-отчёт `htmlcov/index.html`. Эти же проверки запускаются в GitHub Actions.
